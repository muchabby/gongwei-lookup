# 工位一键查询（网页版）

深圳·厦门办公区工位 / 会议室查询工具，单文件网页，双击即可用。

## 使用

打开 `深圳工位查询.html`（本地浏览器直接打开，或下载后打开）：

- **查员工工位**：输入姓名，秒查 城市 · 工区 · 楼层 · 座位号
- **查会议室**：输入「会议室」「洽谈室」或具体编号（如 `201会议室`）
- 点结果自动跳转到对应楼层图并高亮定位；地图支持滚轮缩放、拖拽平移、悬停圆点看姓名

## 数据

- 来源：飞书文档《【深圳】工位图》《【厦门】工位图》
- 范围：深圳 702 人、厦门 294 人、会议室 56 个（数据按周更新）
- 厦门工位图只标姓名、无座位号，故厦门记录座位号为空

## 说明

- 数据由 OCR 自动识别生成，个别姓名可能有识别误差，以原工位图为准
- 本仓库为私有仓库，内含全员姓名与工位信息，请勿外传或设为公开
